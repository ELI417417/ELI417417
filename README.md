### About Me

I'm a machine learning engineer focused on computer vision and NLP. I learn by implementing papers from scratch in PyTorch, running experiments, and wrapping models into interactive demos. Every project here is built for learning — I believe you don't understand something until you've built it yourself.

- 🎯 **Focus:** Computer Vision · Large Language Models · Paper Reproductions
- 🛠️ **Tools:** PyTorch · Transformers · OpenCV · ONNX Runtime · FAISS · Streamlit · Flask
- 📚 **Languages:** Python · C/C++ · SQL
